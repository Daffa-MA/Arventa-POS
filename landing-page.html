FAQ

Pertanyaan Umum

Apakah bisa dipakai untuk banyak toko?

Ya. Arventa POS menggunakan arsitektur multi-tenant. Satu backend bisa melayani banyak toko sekaligus.

Apakah data tiap toko terpisah?

Ya. Setiap toko memiliki data yang terisolasi. Admin toko hanya bisa mengakses data tokonya sendiri.

Apakah bisa pakai printer Bluetooth?

Bisa. Mendukung thermal printer Bluetooth 58mm dan 80mm dengan 3 template struk.

Apakah aplikasi Android bisa offline?

Aplikasi sync data secara periodik. Setting dan katalog bisa diakses setelah sync pertama.

Apakah cocok untuk developer / agency?

Sangat cocok. Ada Developer Console untuk membuat dan deploy tenant baru dengan satu klik.
